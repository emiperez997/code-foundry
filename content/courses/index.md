# Course Index

## Real-World Authentication System
**Slug:** `real-world-auth` · **Level:** Junior / Mixed

A junior developer joins a small startup and gets their first real task: add a login system to the app. This course covers registration, password handling, sessions, route protection, and basic roles — making each security decision explicit and showing what breaks when it's wrong.

---

## Real-World REST API Design
**Slug:** `real-world-api-design` · **Level:** Junior / Mixed

A developer builds the backend API for a task management app while the frontend team waits. This course covers resource modeling, consistent endpoint design, error handling, server-side validation, authentication, and basic documentation — all in the context of a real API contract that another team depends on.

---

## Real-World Database Design
**Slug:** `real-world-database-design` · **Level:** Junior / Mixed

A developer designs the database for a project management app from scratch, with only informal requirements and user stories to work from. This course covers entity modeling, relationships, data types, constraints, queries with JOINs, and safe schema evolution — showing what breaks when each decision is made carelessly.

---

## Real-World Frontend Architecture
**Slug:** `real-world-frontend-architecture` · **Level:** Junior / Mixed

A developer inherits a working React app that nobody wants to touch because it's hard to follow. This course covers component responsibilities, state placement, data flow, API separation, folder structure, and form handling — not as abstract patterns, but as concrete improvements to a messy codebase.

---

## Real-World CI/CD Pipeline
**Slug:** `real-world-cicd` · **Level:** Junior / Mixed

A small dev team deploys manually, skips reviews, and regularly breaks production. This course covers Git workflows, automated checks, test pipelines, environment configuration, and automated deploys — built as a practical response to the real friction a team without process experiences every week.
