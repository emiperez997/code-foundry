## Objetivo

Implementar una vista usando exclusivamente un Design System externo.

## Instrucciones

- No crear componentes custom (salvo layout)
- Respetar tokens, spacing y tipografía
- Implementar estados (loading, empty, error)

## Consideraciones

- Elegir un Design System popular y bien documentado
- Asegurarse de que el Design System elegido tenga componentes que cubran las necesidades de la vista a implementar
- Mantener la consistencia visual y funcional con el Design System seleccionado

## Design Systems posibles:

- Material UI
- Carbon
- Polaris
- Spectrum
