## Objetivo

Diseñar un modelo de datos simple y escalable para una plataforma educativa.

## Entidades mínimas

- User
- Course
- Module
- Video
- Progress

## Consideraciones:

- Cursos con múltiples módulos
- Progreso por usuario
- Escalabilidad futura

## Resultado esperado:

- Diagrama lógico
- Descripción de relaciones
